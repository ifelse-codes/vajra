## Fakest green

**The "SHIP gate" cannot actually see a ship once the branch refs are gone — and every ref it reads is controlled by the same actor it gates.** I proved it live: do real work on a session branch, force-delete it unmerged, delete the origin-tracking ref, and `--check-release` returns READY exit 0 — a never-shipped session is indistinguishable from a shipped-and-cleaned one, with only a warning between them. Add the structural deferral (your own session's unshipped work never blocks its *own* close, only the next one's) and the fetch-staleness limit (origin/main is whatever the last fetch left), and the honest statement is: the Releaser enforces ship *tidiness for actors who keep their evidence*, not ship *truth*. To its credit, the gate says all of this in its own runtime output — the green is hollow at the edges, but it is labeled hollow at exactly those edges.
