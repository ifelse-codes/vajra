## 1. Goal

Sessions 09 and 10 locked chitra's design language for the circular (pie/donut), area, and line
chart families — recorded as `### LOCKED:` sections in `packages/core/README.md`. The **bar chart
still does not carry it**: `packages/core/src/charts/bar.ts` uses raw rainbow `theme.colors[s % n]`
per series, a plain solid `└─` axis (no dashed panel frame, no eyebrow row), no `+` axis ticks, and
no per-series MIN/MAX/AVG/LAST summary. Bring `bar()` up to the same locked language the other three
families already carry, then LOCK it.

## 2. Context — the shared language you are extending (read the existing LOCKED sections first)

Read `packages/core/README.md`'s `## Design Style` section and all three existing `### LOCKED:`
sections (circular, area, line) in full before writing any code — they are the actual spec here,
not this prompt. In summary, every locked family shares:

- **One accent hue + grey tone ramp**, never rainbow color per series. The accent is spent once
  (biggest/primary value); everything else recedes onto the tone ramp
  (`#ECECEF → #C6C6CE → #A4A4AE → #6A6A75`).
- **Series identity via tone + glyph/texture, not separate bright hues**, in monochrome especially.
- **Dashed panel frame** (`┌╌…╌┐`), **eyebrow row** (uppercase, letter-spaced), `+` axis ticks,
  `│` y-guide — the shared panel chrome every locked chart uses.
- **Per-series summary row(s)**: MIN / MAX / AVG / LAST (or the closest sensible analog for bars),
  right-anchored, echoing the sparkline-panel pattern used by line/area.
- **Auto-scale to the data**, empty cells are spaces (never phantom fill or blank braille).

Also check `design-reference/tui-chart.html` for any bar-chart-specific visual cues before
inventing new conventions.
