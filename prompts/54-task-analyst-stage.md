## Type
- **CODE** (first governed SDLC stage). Max **2** assumptions · **2** retries · **~2h** · **1** story ·
  **new chat** · approval token before any commit.

## The job
Make the **Analyst** the specialist that turns intent into the **next governed prompt**:
1. **Intake** — take the intent (the just-finished session + the user's own words; or a fresh vague ask).
2. **Options** — present **exactly 3 candidates A/B/C** (title · one-sentence goal · why-pick · key risk), drawn
   from `ROADMAP.md` (the existing "Present & Prepare" contract).
3. **Generate** — on the user's pick, write **`prompts/NN-task-<slug>.md`** (Vajra's spec: goal + deliverables +
   acceptance / "what must be answered" + guardrails) and update the `TASK.md` pointer.
4. **Delta** — record what the new session **adds / changes / removes** vs the ROADMAP/plan (+/~/−).
5. **Gate** — the next session **cannot start without an approved, generated prompt** (enforcement, not a ritual).

**The artifact is the PROMPT file, not a `spec.md`. No second store.**

## Borrow Engine (step 0)
Study how Spec Kit (`spec.md`), Kiro (EARS requirements), OpenSpec (delta markers) structure requirements +
acceptance — then **fold the best of that shape INTO Vajra's prompt format** (e.g. crisper acceptance criteria in
the prompt's "Output" / "what must be answered"). Borrow the **shape of the thinking, not the foreign file.**

## Design constraints
